# VoxEvolve

**Self-Evolving Voxel World Model**

CoDL Proposal — research directions for a voxel world model with persistent state and autonomous evolution.

**Website:** https://mengmaor.github.io/VoxEvolve/

The static website is in `docs/index.html`; it is self-contained and can also be opened directly in a browser. GitHub Pages publishes the `docs/` directory from `master`.

The page includes a deterministic voxel animation and an interactive architecture diagram. The model name VoxEvolve is provisional.
